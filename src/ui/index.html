Какие действия спрашивать перед выполнением. Оплата, удаление наклейки и отдача предметов в обмене подтверждаются всегда.

У каждого аккаунта может быть свой прокси: весь его трафик (вход, Steam, Торговая площадка, QR) идёт только через него. Если прокси не работает — вход не выполняется, напрямую ничего не уходит.

Добавить список прокси

По одному в строке. Форматы: socks5://user:pass@host:port, http://host:port, host:port:user:pass, user:pass@host:port. Прокси раздаются по кругу.
